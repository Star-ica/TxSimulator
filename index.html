Frequently Asked Questions

Does this execute a real transaction?

No. TxSimulator uses RPC methods like eth_call to run the EVM context against the current state without broadcasting to the mempool.

Why BOT Chain?

BOT Chain offers high throughput and robust RPC infrastructure necessary for rapid, real-time transaction tracing and simulation.

Transaction Input
